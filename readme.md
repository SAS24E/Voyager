
# Voyager

A C++ text-based dungeon crawler built to explore and refine core C++ software architecture, game mechanics, and design patterns.

---

## About
**Voyager** is a terminal-based dungeon crawling game designed as a practical learning project for C++ development. Players navigate through connected rooms using an interactive map system, track location history, manage inventory, and battle enemies.

---

## Features
* **Map & Navigation:** Traverse connected rooms with location tracking and backtracking capabilities.
* **Game Engine Architecture:** Modular components separating player logic, room definitions, enemies, and inventory systems.
* **Console UI:** Text-based user interface and interaction output in the terminal.

---

## Getting Started

### Prerequisites
* A C++ compiler supporting standard C++17 or later (`g++`, `clang++`, or MSVC).
* Git for version control.

### Building & Running

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/SAS24E/Voyager.git](https://github.com/SAS24E/Voyager.git)
   cd Voyager

```

2. **Compile the project:**
```bash
g++ -std=c++17 main.cpp -o voyager

```


3. **Run the game:**
```bash
./voyager

```
